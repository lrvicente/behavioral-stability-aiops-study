## Technical refinement 2: item count explanation corrected

A direct query to the Zabbix API using the same parameters as the
`nightly_export.py` script (`item.get` with `hostids=[12 study hosts]` and
`monitored=true`) returns 972 items, matching the manifest exactly. A raw SQL
query on the `items` table for the same 12 hosts (filtering `host.status=0
AND item.status=0`, with no template join) returns 924 items. The 48-item
difference comes from items resolved through template inheritance by the API
but not visible in a flat join on `items.hostid`.

The previous explanation, recorded in the 2026-05-25 entry as "972 items
effectively generating data (1308 minus 384 prototypes)", uses arithmetic
that does not actually equal 972 (1308 minus 384 equals 924). The correct
explanation is the API-level resolution of template-inherited items. The
canonical study item count remains 972, as reported by the export manifest
and verified today via the API directly. Future paper sections referring to
this number should use the API-based explanation rather than the prototype
exclusion framing.
